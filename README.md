# Destiny of Dragons

[Play Destiny of Dragons](https://benny-yan67.github.io/dragon-wilds-play/)

Original game by Benny. The browser edition uses the phone’s vector dragon art and continuous animations, combat progression, controls, camera and original music. All 145 playable dragons have 7× original attack damage.

Private Co-op and PvP rooms connect to the Destiny of Dragons online server. Each player has a private cloud save. Link phone and laptop browsers once for automatic progress synchronization. Version 4.10 adds ten selectable battlefields, clear adjacent Adventure/Story cards and a bigger Fight button, alongside accounts, automatic saving, 20 upgrades and keyboard controls.
