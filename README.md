# Dragon Wilds

[Play Dragon Wilds](https://benny-yan67.github.io/dragon-wilds-play/)

Original game by Benny. The browser edition uses the phone’s vector dragon art and continuous animations, combat progression, controls, camera and original music. All 145 playable dragons have 3.5× original attack damage.

Private Co-op and PvP rooms connect to the Dragon Wilds online server. Each player has their own local browser save. Phone progress can be copied using Online / Friends in the Android app.
