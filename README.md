# Destiny of Dragons

[Play Destiny of Dragons](https://benny-yan67.github.io/dragon-wilds-play/)

Original game by Benny. The browser edition uses the phone’s vector dragon art and continuous animations, combat progression, controls, camera and original music. All 145 playable dragons have 7× original attack damage.

Private Co-op and PvP rooms connect to the Destiny of Dragons online server. Each player has a private cloud save. Link phone and laptop browsers once for automatic progress synchronization. Version 4.9 adds username/password accounts and automatic match/purchase sync, alongside 20 upgrades, shaded isometric graphics, keyboard-first laptop controls and Story quests.
